# Copper Conservatory — MAGNET LAB

Editable Blender environment and the actual Roblox import for the cream/sage/copper toy laboratory.

The field is surrounded by a rounded porcelain/timber promenade, an arched glass gallery and horseshoe observatory, an asymmetric water garden, curved benches, copper coil workstations, layered planters and folded-leaf trees. Center-field geometry remains quiet so live profile blocks stay legible. Surrounding courts are decorative; existing player bounds remain the circular playing area.

## Files

- `magnet-conservatory.blend`: editable source, with the original default collection hidden and a prepared overview camera.
- `build_map.py`: rebuilds only the `MAGNET_Conservatory` collection; run inside Blender. Source coordinates use studs; temporary export copies convert to metres.
- `magnet-conservatory.glb`: self-contained game export, no external resources or textures.
- `manifest.json`: source colors, alpha, triangle counts and expected bounds/orientation.
- `conservatory-overview.png`: Blender preview.
- `roblox-overview.png`: actual final Roblox Studio screenshot.

## Roblox import

One Model upload: **118724006904787**, approved, owned by group **973060360**. It contains **69 meshes**, **247,496 triangles**, max **12,000 per mesh**. No image assets were uploaded or generated by the importer (no image resources in the GLB and no TextureIDs on inserted MeshParts).

Insert the asset as `Workspace.CopperConservatoryImport`, then run `src/StudioConservatorySetup.luau` in Edit mode. The importer dropped plain material colors, used one metre as one stud and flipped horizontal axes180 degrees. The installer calibrates the90-stud floor, uses the western water court to fix orientation, restores the exact sRGB palette/alpha, anchors all69 MeshParts and disables decorative collision. It wraps the repaired package in an origin-pivoted `BlackHoleArena.ArenaVisuals`, preserving local arena scaling and the `FloorTile` lookup used by the range ring.

The current placed copy has all repairs. The asset is still a linked package: reinserting it or applying a package update can restore the raw imported scale/colors. Run the installer on a fresh insertion; its asset-copy repairs are not a new published asset version. No unlink or auto-update setting was changed. The optional AutoUpdate metadata read was unavailable to MCP; the package was otherwise inserted and verified normally.

At default150%, the whole decorative island is about315×315studs, the playing floor diameter135studs and its top0.3stud. The magnet stays9stud reach; character/block/tool sizes are unchanged. The environment animates as69 meshes rather than the previous1231 visible native parts. Existing64 wall pieces and the hidden support floor still own collision.

Old visuals, hidden ArtPass and lighting are preserved in `ServerStorage.BeforeConservatory_20261109`. Lighting now uses warm daylight, restrained bloom, subtle air and a mild color grade. Do not rerun the earlier blanket `StudioArtPass.luau` recoloring pass on this new environment; use its source palette/installer.
